# 管理后台架构

## 一、现状

- 技术：Next.js App Router + 自研组件（类 shadcn 风格），`/admin` 路由。
- 鉴权：middleware 拦截 `/admin/:path*`，Cookie JWT + RBAC（`requirePermission`）。
- 模块：24 个（工作台/线索/案例/服务/文章/Banner/媒体库/表单/套餐/订单/优惠券/合同/会员/项目/实名配置/AI配置/微信设置/支付设置/回收站/登录日志/操作日志/管理员）。

## 四、通用交互规范

- 列表：搜索 + 分页 + 筛选 + 排序。
- 编辑：表单校验（zod）+ 保存留痕。
- 删除：软删除（进回收站）+ 二次确认。
- 状态修改：走状态机，非法流转禁用按钮 + 后端拒绝。
- 操作日志：关键写操作记录前后快照（现状已有 AdminOperationLog）。

## 六、数据一致性

- 后台改套餐/服务/案例/文章 → 直接落库 → 官网/小程序读取同一数据。
- 改价**不重编小程序**（数据来自 API）。
- 若引入缓存：内容变更需同步失效。

## 七、安全

- 后台与接口响应 `X-Robots-Tag: noindex`。
- 密钥类配置（微信 AppSecret/商户私钥）仅超管可见，回显掩码。
- 操作日志 + 登录日志可审计。
